# ADR-0025: Web Delivery Surfaces

Status: Accepted

Date: 2026-08-27

## Decision

The learner product is one responsive website containing public, SEO, account, learning, exam, and billing flows. No native learner application is in scope. Admin is a separately protected web surface with independent authorization assumptions.

## Consequences

Mobile web is a complete experience. PWA capabilities remain optional web capabilities. Admin isolation is designed from the beginning.
