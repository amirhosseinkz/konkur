# ADR-0024: Production Successor

Status: Accepted

Date: 2026-08-27

## Context

Prototype Zero proved an exam-driven learning hypothesis but has direct-file architecture, unverified legacy data, no backend, and no commercial operations.

## Decision

Build a production successor governed by `project/` and `docs/`. Preserve Prototype Zero as historical evidence. Computer Engineering MSc is the first complete vertical; National and Master's Entrance are first-class platform families; Doctoral Entrance is future scope.

## Consequences

Prototype architecture is not extended into production. Reuse requires explicit review. GA can include one complete vertical because platform completeness and content breadth are separate release dimensions.
