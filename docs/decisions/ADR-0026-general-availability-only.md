# ADR-0026: General Availability Only

Status: Accepted

Date: 2026-08-27

## Decision

There is no public MVP, beta, or partial production release. Milestones before GA are internal evidence checkpoints. Private research is allowed when it is explicitly non-production and participants understand its status.

## Consequences

Public release waits for all launch gates. Internal validation remains necessary so the policy does not become an excuse to avoid evidence or defer user learning.
