# Design Principles

Status: Direction accepted; visual system pending

## Product Character

Konkur should feel focused, precise, fast, credible, and distinctly Persian. It must not resemble a noisy tutoring marketplace, a school portal, or a generic dashboard template.

## Principles

1. The next study action is visually dominant.
2. Dense information remains scannable through hierarchy, not decorative cards.
3. Exam pressure is reduced through clarity, not gamified anxiety.
4. Progress uses evidence and neutral language.
5. Source and verification status are understandable without overwhelming the learner.
6. Mobile is a complete study surface, not a compressed desktop afterthought.
7. Persian typography, numbers, RTL flow, formulas, code, and mixed-direction content are designed deliberately.
8. Motion communicates state or continuity and always supports reduced motion.
9. Paid boundaries are transparent and never interrupt an active exam unfairly.
10. Accessibility is part of visual quality.

## Required System Work

Milestone 2 must define typography, spacing, color, elevation, motion, icons, data visualization, content layouts, forms, feedback, exam controls, and responsive behavior as reusable tokens and components.

No final brand style, color system, or typeface is selected by this document.
